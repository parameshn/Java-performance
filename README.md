# Java Performance

Notes and learning materials based on *Java Performance: In-Depth Advice for Tuning and Programming, Java 8, 11, and Beyond* by Scott Oaks.

## Topics Covered

- **JVM:** Architecture, JDK vs JRE, and containers
- **Garbage Collection:** GC algorithms, generational GC, and collector selection
- **JIT Compiler:** HotSpot, tiered compilation, optimizations, and deoptimization
- **Performance Metrics:** Measuring and understanding application performance
- **Benchmarking:** Microbenchmarks, mesobenchmarks, and macrobenchmarks
- **Platforms:** Hardware and platform considerations

## Purpose

To understand how Java applications execute and how to analyze and improve their performance through JVM tuning, garbage collection, compilation, and benchmarking.

## How to Use

1. Clone or download this repository.
2. Open the Markdown files in VS Code or any Markdown viewer.
3. Study each topic and take notes.
4. Apply the concepts to Java programs and measure their performance.
